# Mahaboob Basha Shaik — DevOps Portfolio

Responsive single-page portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
- Extract the ZIP.
- Open `index.html` in a browser. No build tools are required.

## Before publishing
- Verify that your LinkedIn and GitHub URLs are correct and public.
- Add links to the repositories for both projects if available.
- Review all project descriptions and skills for accuracy.
- The contact form opens the visitor's email app; it does not send messages through a server.
- Your uploaded portrait is stored in `assets/profile.jpg`.

## Deploy
You can publish this folder using GitHub Pages, Netlify, or any static web host.
